# 透明实验室

主题围绕电子开发中的“连接、信号与观察”：页面像放在柔光实验台上的透明仪器，玻璃是结构材料，电路与波形是主要视觉，不使用通用宣传页的彩色装饰卡片。

## 视觉系统

- 冰灰 `#e8eef5`：空间底色。
- 珍珠白 `#f8fbff`：玻璃高光。
- 深海蓝 `#182d49`：正文与大标题。
- 信号蓝 `#376bb4`：链接、波形与交互反馈。
- 雾紫 `#c8c3e0`：背景折光。
- 钛金 `#b99b7a`：少量金属触点。

字体使用系统可用的 Bahnschrift / Segoe UI / 微软雅黑，保持中文阅读质量。标题通过尺寸、字重和留白形成层级，不以单个彩色单词强调。

## 材质与运动

玻璃需要可辨识的背景透射、柔化、内侧高光、外沿细边与接触阴影。导航、主视觉、产品展示的玻璃厚度和圆角不同。文字区保持足够不透明度，透明只用于层次，不牺牲阅读。

桌面指针移动仅调整背景光环和玻璃高光。鼠标参照区域、文字、芯片和波形卡片保持固定，不对文字做倾斜或透视变换，避免模糊与边界反馈导致跳动；手机不启用跟随。首次进入使用一次短淡入；尊重减少动态效果的系统设置。所有必需信息、导航及备案信息不依赖动画或 JavaScript。

二级页面沿用同一玻璃空间，避免首页与下载、项目、关于页面各自为政。手机将双栏改为单栏，玻璃仪器缩放但不横向溢出。
