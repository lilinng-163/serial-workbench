# 波形样式与坐标单位

在波形页顶部点击「波形设置」，可以修改当前页面的坐标轴名称、单位和默认曲线样式。每个波形页单独保存设置；保存后立即生效，重新启动后恢复。

在图例中的通道名称或数值上右键，选择「曲线设置」，可单独修改该通道的颜色、线宽和线型。线宽支持 0.5～8 像素，线型包含实线、虚线、点线和点划线。直接修改选项会自动取消「使用默认样式」，为当前通道保存独立样式；重新勾选或选择「恢复默认样式」后，通道重新沿用页面默认值。左键点击仍用于显示或隐藏曲线。

再次打开时显示当前通道已保存的值，并保留本次运行中上次设置窗口的大小、位置和设置页。放大窗口后，表单保持紧凑排列，额外空间用于底部留白。内置演示的波形名称使用中文；设备自定义通道名保持原样。

「默认曲线样式」用于没有单独设置的通道，包括后续出现的新通道。自动配色沿用主题色板；也可以选择统一的默认颜色。颜色按钮始终可点击，点击后自动取消「自动配色」；在通道设置中也会取消「使用默认样式」，无需先手动取消勾选。取消选色会保留原颜色，取消整个设置窗口则不保存修改。显示或隐藏通道、单独设置的样式都会随页面保存。

X、Y 轴支持自定义名称和单位，也可留空。「常用单位」菜单提供时间、频率、电学、温度、角度和力学等单位。输入框下方的按钮可以直接选择 µs、ms、°C、Ω、µA、°、m/s² 等符号；选择会替换当前单位，仍可继续手动编辑。

X 轴的「每采样间隔」控制显示刻度：`X 刻度 = 原始采样序号 × 间隔`。例如设备以 20 ms 周期发送采样，可以将名称改为「时间」、单位设为 `s`、间隔填 `0.02`。程序不自动推断采样周期，这一换算也不等同于接收时间戳。

Y 轴单位用于标注坐标轴、图例读数和悬停值，不做数值换算。应填写与设备发出的数值一致的单位；共享 Y 轴适合相同单位的曲线，混合单位时可留空。原始采样、复制的原始读数及 MCP 数据保持原值。

「全部恢复默认」会在点击「保存」后恢复页面默认样式、坐标轴名称和单位、采样间隔，以及通道可见性。点击「取消」不会改变当前设置。自动缩放和跟随最新只调整视图，不清除样式或单位。
