# 串口控制

在标签栏点击 **+ → 新建控件页面 → 串口控制**，选择已在收发页建立的串口连接。页面支持滑块、数字输入、开关、按钮和下拉框。可创建多个控制页面，分别绑定不同设备。

每个控件都有名称、参数名、发送模板和当前值。点击「编辑」配置，保存后自动记住；卡片右上角的垃圾桶只删除该控件。数字控件可设置范围、步长和小数位数。下拉选项每行写一项，例如：

```text
待机=0
低速=1
高速=2
```

显示名称为「低速」时，发送值为 `1`。开关的关闭、开启分别使用 `0`、`1`；动作按钮发送编辑窗口中的固定值。

## 控件组和布局

点击「新建组」把一套相关参数放在一起，例如「电机参数」「温控参数」。管理菜单支持重命名、复制和删除组；编辑控件时可修改「所属控件组」。切换组只切换界面，不发送参数。每页最多 32 组，每组最多 64 个控件。

默认使用自由布局：拖动卡片标题栏可移动控件，拖动卡片边缘或右下角可调整大小。调整窗口宽度时，卡片的横向位置和宽度会按比例跟随，高度和纵向位置保留；卡片至少保留足够空间显示输入框、按钮和文字。位置和尺寸按控件组保存，重新打开时先恢复已保存的布局，空间不足可用滚动条查看画布。

卡片右上角的垃圾桶可直接删除该控件；「⋯」菜单提供「移至最上层」「移至最下层」，用于控件重叠时调整图层。删除、移动、缩放或切换图层均不发送串口数据。

也可选择「两列排列」或「单列排列」，两列在窄窗口下自动变为单列，各行卡片对齐。「整理排列」可重新整理卡片位置与默认尺寸，保留参数和命令。报文预览默认折叠，点击「报文预览」展开实际文本和 HEX 字节。旧版控件组升级后进入自由布局，控件参数保留。

滑块的拖动坐标与数值精度分别处理，0～100、步长 0.0001、小数 4 位可正常保存和发送；需要比拖动更细的调整时，可在旁边的数字输入框直接填写。错误原因显示在编辑窗口底部，保存按钮上方，无需滚动查找。

## 常用控件组与批量清空

工具栏的「常用控件组」提供以下模板，每次添加一个独立组并切换到该组，保留原有控件；重复添加时名称自动编号。

| 模板 | 控件 |
| --- | --- |
| PID 调参 | Kp、Ki、Kd、目标值、输出上下限、使能、积分清零 |
| 电机调速 | 转速、占空比、加速度、转向、使能、停止 |
| 温度控制 | 目标温度、回差、采样周期、模式、加热使能 |
| PWM 输出 | 频率、占空比、通道、极性、输出使能 |

模板默认全部手动发送，使用 `SET {key} {value}` 加 CRLF 行尾。例如 Kp 为 1 时发送 `SET kp 1.000`。这些是可编辑的命令示例，设备端需实现相应协议和控制逻辑；上位机不会执行 PID 运算、联动各参数或判断设备是否已生效。先按设备协议调整范围、单位和报文模板，再发送。原「添加示例」移至此菜单的「基础控件示例（添加到当前组）」。

点击「清空全部」可一次清空本页面所有组中的控件；「管理组 → 清空当前组控件」只处理当前组。确认窗口显示范围和数量，默认选中取消。清空会保留控件组、串口连接、小窗设置和收发历史，不发送数据；此操作无法撤销。其他控件页面不受影响。

## 手动与自动

每个新控件默认手动发送，调节后可展开报文预览，再点击该控件的「发送」。动作按钮点击「执行动作」发送。

每个控件独立勾选「自动发送」。调节后首个值立即进入发送调度，此后同一控件最多每 50 毫秒发送当前最新值，持续滑动期间也会更新，停止后保留最终值。串口发送队列积压时合并中间值，避免旧命令持续排队。动作按钮仍只在点击时发送。控件的发送方式随配置保存；旧版页面开关会迁移到原有各控件。

数值变化停止 300 毫秒后统一保存配置，拖动期间不逐次写文件；正常关闭窗口时仍会保存当前值。

恢复设置、添加示例、编辑模板、启用自动发送、选择连接本身均不发送。切换连接、切换组、断线重连、关闭自动发送或离开页面会取消待发送命令。文件传输期间禁止控件发送；不会在恢复连接后补发之前的设置。

## 收发小窗

点击工具栏的「收发小窗」，可打开独立窗口查看当前串口的发送记录与设备回显，调节控件时无需切换到收发页。小窗可拖动、缩放，也可关闭后再次打开；尺寸、位置、文本编码、时间戳、HEX 显示和跟随选项会保存，数据字体跟随全局设置。重新启动软件后按需打开，不会自动弹出。

小窗与收发页、MCP 共用原连接，各自读取历史，不会抢占串口或消耗其他页面的数据。切换控件页的数据来源时，小窗同时切换并清除上一设备的显示。暂停只停止小窗刷新，后台仍接收，继续后补充显示；垃圾桶仅清空此小窗，不删除原收发页或 MCP 历史。首次打开显示近期记录，长时间暂停后，超过历史缓冲区的旧数据可能已被覆盖。

底部可输入文本命令，选择行尾，按回车或点击「发送」。此处使用小窗所选的 UTF-8、GBK 或 ASCII 编码；HEX 按钮只改变显示方式，不改变手动发送格式。文件传输期间禁止发送，避免干扰传输协议。发送成功表示报文已交给连接，设备是否接受或执行仍需看接收回显。

## 文本模板

使用 `{key}` 代入参数名，`{value}` 代入当前值。例如参数名 `speed`、值 `1200`：

| 模板 | 实际文本（不含行尾） |
| --- | --- |
| `SET {key} {value}` | `SET speed 1200` |
| `{key}={value}` | `speed=1200` |
| `{"speed":{value}}` | `{"speed":1200}` |

支持 UTF-8、GBK、ASCII 编码，行尾可选无、LF、CR、CRLF。预览中的 `\r`、`\n` 表示实际的回车、换行字节；模板中直接输入的反斜杠不会转义。JSON 字符串值需要自行处理引号与转义。

## HEX 字节模板

填写成对十六进制字节及带类型的数值占位符，例如：

```text
AA 55 {value:u16le} 0D 0A
```

值为 `1200` 时实际发送 `AA 55 B0 04 0D 0A`，不额外附加文本行尾。

| 类型 | 含义 |
| --- | --- |
| `u8` / `i8` | 无符号 / 有符号 8 位整数 |
| `u16le` / `u16be`、`i16le` / `i16be` | 16 位整数 |
| `u32le` / `u32be`、`i32le` / `i32be` | 32 位整数 |
| `f32le` / `f32be` | IEEE 754 单精度浮点数 |

`le` 表示低字节在前，`be` 表示高字节在前。超出范围、将小数写入整数、非法 HEX 或未知占位符均会报错，禁止发送。每条报文最多 4096 字节。协议需要校验和、应答或重试时，须先按设备协议实现；此页面不会自动附加校验或判断设备是否已执行。

## 设备端接收

设备端需约定相同的命令格式。例如用逐行接收方式解析 `SET speed 1200\r\n`，查找 `speed` 后将 `1200` 写入目标转速变量；HEX 示例则按帧头、长度及小端数值解析。控件的成功提示表示驱动接受了报文，设备是否应用参数应通过设备返回数据确认。

发送记录通过原串口连接保留在收发历史中，GUI 和 MCP 可按该连接读取。页面只支持串口，不会把命令发到历史 SSH、TCP 或 UDP 连接。「添加示例」仅添加可编辑配置，不会自动连接或发送。


UART0 回显验证可参考 [ESP-IDF 示例](../examples/esp-idf/uart-control-echo.cpp)。示例先阻塞等待一个字节，再以零超时取走已缓存数据并立即回显，适用于 UART0 外接 USB 转串口，115200、8N1。原生 USB Serial/JTAG 需使用相应 USB 驱动。示例用于回显，不解析或执行参数，未纳入桌面程序和安装包；未在实体 ESP32 上烧录验证。
