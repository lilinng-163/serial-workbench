# 验证记录

日期：2026-10-12。环境：Windows 11、Python 3.14.4、PySide6 6.12.0、MCP Python SDK 1.30.0。完整依赖见 `requirements-lock.txt`。

## 自动化测试

`python -m pytest -q`：85 项通过（0.6.0）。

- 串口 `loop://`：自定义波特率、文本与二进制往返、数值波形、断开后禁止发送。
- TCP：真实本机 socket 双向收发、多客户端定向发送、客户端退出后服务端继续监听。
- UDP：真实本机 socket 收发、原始二进制、数据报边界、对端地址。
- 数据：两个读者互不消耗记录、游标分页、过滤、长轮询唤醒、缓冲区覆盖提示及内存限制。
- 波形：跨接收块拼接、CSV、JSON、命名数值、无效数值和超长行处理。
- MCP：标准协议初始化、工具发现、两个 HTTP 客户端同时读取、读写权限、创建与关闭连接、STDIO 桥接；等待新数据时其他工具仍能响应。
- Qt：界面发送、定时发送、清屏保留共享历史、波形切换、终端 ANSI 清屏、UTF-8 分片、Ctrl+C 和方向键。
- 启动与连接：重复启动唤醒已有窗口、关闭后释放实例锁；阻止程序内重复打开同一串口；MCP 端口冲突提示及释放端口后的重试；界面/MCP 使用实际进程账户信息。串口重复打开测试使用模拟通道，不访问硬件。
- 日志显示：ESP ANSI 日志以 1、2、7、31 字节等分块输入，跨块颜色码和中文、CRLF 均正常；实时更新无换行提示符；不同对端分别拼行；按完整行过滤；超长行显示状态有界。Qt 实测无多余空行，HEX/共享日志仍保留原始字节。
- 界面交互：监视/终端共用显示区，切换时发送栏显隐正确，历史保留，终端直接发送 Tab/方向键/Ctrl+C；主题、字体、字号、时间戳和模式保存恢复；清屏后切换时间戳不恢复已清空的显示；连接按钮的连接中、正常连接、断开、重连、出错状态；动画中途反向切换和下拉展开/收起。
- 字号：真实 Qt 滚轮事件验证 Ctrl+滚轮实时更新字号框、监视、终端和发送文本；普通滚轮不修改字号；字号边界及无单位显示。
- 彩色打印：监视和终端的实际文字格式包含 ANSI 前景/背景色；16 色、256 色、RGB、跨块颜色码、颜色复位，原始共享记录保持不变。
- 复位恢复：模拟接收故障、端口暂时不存在、发送故障及恢复；连接 ID 和已有历史保持，恢复后继续收数，波形半行与显示解析器重置。等待期间可手动停止，首次打开失败不无限重试，无输出时不误判掉线，失败发送不自动重放，默认 NULL 不访问驱动。全部使用模拟驱动，不打开实体串口。

完整测试包含 HTTP/STDIO MCP 验证。

- 连接标签与分屏：串口多次重连复用同一个 ID、标签和原始历史；串口回环与真实本机 UDP 同时显示并分别发送，验证发送目标不会跟随另一个标签切换；收发和波形同时显示及独立开关；合并分屏后保留发送文本；右键操作与关闭单个标签不影响其他连接。
- 参数与帮助：端口、波特率、数据位、校验、停止位、流控和网络端口收到滚轮事件时不改变值；界面无演示入口；内置波形帮助包含 LF/CRLF、JSON 和 C 示例。
- 权限记忆：开关立即保存，编辑中的无效波特率不影响权限保存；关闭并重新创建窗口后恢复，关闭权限也会立即保存。
- JSON/XML：跨块 UTF-8、嵌套 JSON、XML 属性/CDATA/注释、混杂日志与 ANSI 颜色码、格式筛选、无效输入、数量和长度限制；各对端独立解析和游标；开启前不解析，清屏不重新显示旧解析结果，原始历史不变。
- MCP 总览与审计：总览返回全部连接及协议数量，不指定连接 ID 时同时读取串口与网络事件；读取结构化结果；不同 HTTP 客户端名称区分，STDIO 桥保留上游名称；拒绝写入也记录失败原因，发送参数仅记长度。
- 客户端配置：四个一键按钮分别在隔离的临时用户目录写入配置并完成真实 HTTP/STDIO 检查；JSONC 注释、字符串、其他服务器和 TOML provider/profile 保留；备份与无效配置不覆盖验证。没有修改真实 AI 客户端配置。

- 0.5.1 设置恢复：保存终端模式和自动解析后，重新打开连接仍显示终端并隐藏发送栏；同一接收数据同时进入终端和结构化列表，查看解析结果不停止接收。修复前新增用例在当前页索引断言失败，修复后通过。
- 0.5.1 分屏关闭：关闭当前分屏的最后一个连接后，选中仍在运行的连接，保留其发送草稿并正常保存显示设置。
