# Serial Workbench 0.15.41

- 新增 OpenOCD 烧录标签页，每块板子分别保存目标、探针、固件、任务和运行日志。多个不同探针可并行执行；并行任务要求明确且不同的探针序列号。
- 支持开发板或“调试器 + 芯片”配置，可搜索配置库；提供传输方式、调试时钟、初始化、复位、校验和运行选项，以及通用烧录与 Espressif 多 BIN 分段流程。
- 配置可导出、导入 JSON，便于复用和交接。导入不会自动连接或烧录；程序、配置库和固件路径仍指向本机文件。
- GUI、CLI 和 MCP 共用页面、配置与任务。新增独立的 OpenOCD 权限开关，支持枚举、执行预览、启动/取消、日志读取及配置导入导出。
- 大窗口左右显示配置与日志，小窗口使用完整标签页；保持左侧参数栏，优化标签衔接，移除常驻拖动提示、“专注日志”和快速方案下拉。

Windows x64 提供安装包、便携 ZIP、单文件 EXE 和 SHA-256 校验文件。需要另外安装适配目标的 OpenOCD 与调试器驱动；恢复页面不会自动执行任务。

OpenOCD 的 27 项 Windows 测试、14 项 MCP 协议测试及发行目录 HTTP/STDIO 检查已通过，浅深色和紧凑布局已实窗检查。任务验证使用模拟进程；真实 OpenOCD 仅验证版本和无硬件 Tcl，尚未完成实体多板烧录验证。

## English

- Add OpenOCD tabs with separate board/probe/firmware settings, jobs and logs. Concurrent hardware jobs require distinct explicit probe serial numbers.
- Search board, adapter and target configurations; configure transport, clock, initialization, reset, verification and run behavior. Support generic flashing and Espressif multi-segment BIN workflows.
- Import and export JSON configurations through the GUI and MCP. Imported paths refer to local files; importing or restoring a page never starts flashing.
- Share pages, configurations and jobs across the GUI, CLI and MCP, with a separate OpenOCD access switch and existing AI write permission checks.
- Use side-by-side configuration and logs in wide windows and complete tabs in compact windows. Preserve the connection sidebar and simplify the tab headers and toolbar.

Windows x64 installer, portable ZIP, single-file EXE and checksums are provided. Install the appropriate OpenOCD distribution and probe drivers separately.

All 27 Windows OpenOCD tests, 14 MCP protocol tests and packaged HTTP/STDIO checks passed. Light, dark and compact layouts were inspected in native windows. Job tests use a process fixture; real OpenOCD checks cover version reporting and hardware-free Tcl only, not physical multi-board flashing.
