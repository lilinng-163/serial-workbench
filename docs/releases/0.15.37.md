# Serial Workbench 0.15.37

将串口姿态数据直接显示为 3D 模型，并改善持续接收时的拖动与页面切换。

- **3D 模型**：导入 STL、OBJ、PLY；分别绑定位置 XYZ、欧拉角或四元数，支持命名数据流、轴交换与反向、模型初始对齐、手动平移、比例与颜色。支持适配视图、相机参数和可调抗锯齿，具体采样数取决于显卡。
- **清晰的设置**：未绑定字段明确标注为偏移常量；常用界面简化旋转顺序，已有配置保持兼容。修复取景、常量四元数和长数字显示；相机拖动后参数同步。模型参数标签衔接与过渡动画统一，任务栏图标只显示透明背景的 Logo。
- **MCP 与配置交接**：提供模型导入、状态读取、参数修改、视口截图及版本化 JSON 配置导入导出，共 24 个 MCP 工具。GUI 和 AI 共用模型、配置及校验；写权限、协议权限和 revision 冲突保护继续生效。导出配置不包含认证信息，模型文件需单独传递。
- **持续接收更顺畅**：按游标定位共享历史，日志分批插入，隐藏收发页持续跟进；积压补绘主动让出事件循环。合并模型重绘请求，并限制拖动时参数面板的刷新频率，减少拖动和切回收发页时的阻塞。
- **Agent 接入**：26 个客户端适配入口、17 个 skill 安装目标，增加搜索、配置导出和品牌图标；内置指南与安装 skill 同步更新。部分客户端依版本使用手动导入，未声明全部第三方客户端均已实连。
- **Windows 升级**：安装器识别同目录的 GUI、后台实例和 MCP 桥，经确认保存退出后更新；维护期间阻止重新启动。静默安装仅在显式指定 `/CLOSEAPPLICATIONS` 时关闭相关进程；无法解除的文件锁仍会明确报错。

推荐 `SerialWorkbench-0.15.37-windows-x64-setup.exe`。另提供便携 ZIP、单文件 EXE 和 `SHA256SUMS.txt`，不需要另装 Qt 或 Python。升级后在“设置 → AI / MCP”更新 skill 与 Agent 配置，再重载 MCP。

发行验证：完整原生 CTest 22/22，实际打包目录的 MCP/CLI/3D 集成、隔离安装升级卸载，以及便携/单文件启动与缓存修复全部通过。

实机验证使用 ESP32-S3、115200 波特率和约 20 Hz 的三个轴轮流姿态演示：约 65 秒采集 1317 个连续帧，没有帧号缺口或解析拒绝；鼠标拖动及切回收发页未发现持续积压。这是该设备和显卡上的验证，不是所有硬件的帧率保证。当前网格导入不含纹理、材质或骨骼动画，截图需要可用的桌面 OpenGL 环境。

## English

- Import STL, OBJ and PLY meshes, and bind translation, Euler angles or quaternions to named telemetry streams. Configure axis mapping, initial alignment, manual transforms, color, camera and hardware-supported multisampling.
- Clarify unbound constants, simplify the common rotation controls while preserving saved conventions, and fix framing, constant quaternions and clipped numbers. Synchronize camera fields, refine model tab transitions and use a transparent taskbar logo.
- Expose model import, state, configuration, viewport capture and versioned JSON import/export through MCP, bringing the tool count to 24. Preserve GUI synchronization, permissions and revision checks. Configuration exports exclude credentials; mesh files are transferred separately.
- Seek shared history by cursor, batch log inserts, keep hidden receive views current and yield during backlog processing. Coalesce model redraws and throttle camera field refreshes during dragging.
- Provide 26 client adapters and 17 optional skill destinations, with searchable Agent settings, configuration exports and updated icons. Version-dependent clients may require manual import; individual third-party client connectivity is not universally verified.
- Coordinate Windows upgrades with same-directory GUI, background runtime and MCP bridge processes. Save and close after confirmation; silent shutdown requires `/CLOSEAPPLICATIONS`. Unresolved locks remain explicit failures.

The setup installer is recommended; portable and single-file builds include their runtimes. Update skills and Agent configuration, then reload MCP after upgrading. An ESP32-S3 test captured 1317 consecutive frames at approximately 20 Hz over 65 seconds, including real dragging and receive-tab switching, without persistent display backlog. Rendering performance remains hardware-dependent; textured or animated meshes are not supported.
