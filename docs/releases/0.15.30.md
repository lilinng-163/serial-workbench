# Serial Workbench 0.15.30

收发搜索与界面修复更新。

- 收发页、收发小窗及 JSON/XML 页新增 Aa（大小写）、ab（全词）、.*（正则）和 &&（逻辑）开关。
- 支持 `温度 && 报警 || 故障` 等组合条件，`&&` 优先；双引号保护包含运算符的内容，正则与逻辑可组合，设置会保存。
- 暂停时也可重新筛选现有日志；错误表达式有边框与悬停说明；JSON/XML 详情跟随可见记录。
- 修复 SSH 草稿切回串口的显示模式，改善默认窗口高度及标签重命名的文字、下划线与图标间距。

推荐下载 `SerialWorkbench-0.15.30-windows-x64-setup.exe` 安装版。另提供单文件 EXE、便携 ZIP 和 SHA-256 校验文件；无需安装 Qt 或 Python。升级前关闭工作台与 MCP 桥，安装器会使用原安装目录并保留设置。

## English

- Add case-sensitive, whole-word, regex and logical search switches to receive logs, serial monitors and JSON/XML records.
- Support AND/OR precedence, quoted terms and combined regex/logical matching; retain settings and allow filtering while paused.
- Keep shared MCP history intact, explain invalid expressions and align JSON/XML details with visible rows.
- Fix SSH-to-serial draft view restoration, improve default window height and refine inline tab renaming.

Use the Windows x64 setup installer for normal installation. A single-file launcher, portable ZIP and SHA-256 checksums are also available. Close the workbench and MCP bridge before upgrading; settings are retained.
