# Serial Workbench 0.15.32

版本回溯、Agent skill 配置与串口控制体验更新。

- **版本回溯**：设置中查看最近三个正式版本的特性，后台下载安装包并校验大小与 SHA-256，确认后再安装。窗口底部显示当前运行版本。
- **skill 配置**：设置中可安装或更新 Agent 使用指南；安装器默认勾选本机已检测到的受支持 Agent，可手动取消。支持 Codex、Claude Code、OpenCode、Pi、Hermes、OpenClaw、Grok Build 和 Gemini CLI，已有不同内容先备份，不修改 MCP 配置。
- **脚本与 MCP**：试解析 HEX 样本随设置保存，MCP 可同步读取和修改；revision 保护未保存的样本与代码。移除独立 AI 提示词窗口，统一由 skill 说明脚本编写和试解析流程。
- **串口控制**：修复控件组下拉显示和切换、删除确认框遮挡；自由布局横向跟随窗口宽度，保留拖动与缩放。清空入口统一为「清空全部」，卡片以「图层」文字提供层级操作。
- **界面**：Windows 文件选择使用系统窗口；水平滑块、图层入口与页面图标统一样式。保留 GUI / AI 共用连接和独立读取。

推荐下载 `SerialWorkbench-0.15.32-windows-x64-setup.exe`。另提供单文件 EXE、便携 ZIP 和 `SHA256SUMS.txt`，运行无需安装 Qt 或 Python。升级前关闭工作台与 MCP 桥；安装器沿用原目录并保留配置。使用 Agent 的用户升级后重载 MCP 连接，并在设置中更新 skill。

## English

- Review the latest three stable releases in Settings and download installers in the background, with size and SHA-256 verification before explicit installation. The status bar shows the running version.
- Install or update Agent skills from Settings. The installer preselects detected supported Agents, allows deselection, backs up different existing content and leaves MCP configuration unchanged.
- Save parser trial HEX samples and synchronize them over MCP. Revision checks protect unsaved code and samples. A shared skill workflow replaces the separate AI prompt window.
- Fix control-group menus and deletion dialogs. Free-layout cards follow window width while retaining drag and resize behavior. Consolidate clearing and clarify layer actions.
- Restore native Windows file pickers and unify themed sliders and control icons, while preserving shared GUI/AI sessions and independent reads.

The Windows x64 setup installer is recommended. Single-file and portable builds plus SHA-256 checksums are also available; no Qt or Python SDK is required. Close the application and MCP bridge before upgrading. Existing installation paths and settings are retained. Reload the Agent MCP connection and update its skill in Settings after upgrading.
