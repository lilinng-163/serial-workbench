# Serial Workbench 0.15.33

主题色自定义与界面一致性更新。

- **主题色**：设置 → 外观 → 主题色，支持选色盘、`#RRGGBB` / `#RGB` 输入、格式提示和恢复默认；应用或离开输入框立即保存，重启后恢复。
- **浅色/深色同步**：自定义色同步背景、面板、按钮、选中状态、标题栏、关于页链接、分离窗口和串口收发小窗；按钮文字按相对亮度自动选择黑色或白色。
- **可读性**：检查极浅、极深与高饱和颜色；深色主题的选色盘、窄设置窗口和背景图组合也保持可用。
- **保持不变**：GUI 与 AI 继续共享连接并各自读取历史；MCP 的 17 个工具、协议权限、脚本读写/离线试解析和原生搜索保持 0.15.31 / 0.15.32 的行为。

推荐下载 `SerialWorkbench-0.15.33-windows-x64-setup.exe`。另提供单文件 EXE、便携 ZIP 和 `SHA256SUMS.txt`，运行无需安装 Qt 或 Python。升级前关闭工作台与 MCP 桥；安装器沿用原目录并保留配置。使用 Agent 的用户升级后重载 MCP 连接，并在设置中检查 skill 与地址。

## English

- **Theme color**: choose with the color picker or enter `#RRGGBB` / `#RGB` in Settings → Appearance → Theme color. Invalid values keep the current color; Apply, leaving the field or Return saves immediately and the choice survives restarts.
- **Light/dark sync**: the chosen accent tints backgrounds, panels, buttons, selections, window captions, About links, detached windows and the serial receive monitor. Button text switches between black and white based on relative luminance.
- **Readability**: extreme light, dark and saturated colors are checked, together with the dark-theme picker, narrow Settings layouts and background images.
- **Preserved behavior**: shared GUI/AI connections with independent reads, all 17 MCP tools, protocol permissions, parser read/write/offline validation and native GUI search remain unchanged.

The Windows x64 setup installer is recommended. Single-file and portable builds plus SHA-256 checksums are also available; no Qt or Python SDK is required. Close the application and MCP bridge before upgrading. Existing installation paths and settings are retained. Reload the Agent MCP connection and check its skill and endpoint in Settings after upgrading.
