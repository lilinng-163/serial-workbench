# Serial Workbench 0.15.15

## SSH 终端

- Shift+方向键按字符或跨行选择，Ctrl+Shift+左右箭头按词选择，Shift+Home/End 选择到行首或行尾，Ctrl+Shift+Home/End 选择到当前屏幕文本起止。选择过程不移动远端光标。
- Ctrl+C 有选区时复制并清除选区，无选区时发送中断信号；复制后再按一次可中断远端程序。长按复制不会误发中断。Ctrl+Shift+C 和 Ctrl+Insert 仅复制，Ctrl+Shift+V 和 Shift+Insert 粘贴，Esc 清除选区。
- 从当前光标用键盘选中的同一行输入，可按一次 Backspace 或 Delete 整段删除，由远端命令行处理并回显。鼠标选区、跨行历史输出，以及选中后已被新输出刷新或因窗口缩放改变的选区仍用于复制，避免误删当前输入。
- 修复中文等宽字符和补充 Unicode 字符的选择边界，提升浅色、深色主题下选中文字的对比度。断开连接后仍可选择和复制已有内容。

## 界面修复

- 设置窗口和波形样式、坐标、脚本、JSON 助手、文件传输、更新、SSH 认证等二级窗口可继续缩小，内容在需要时滚动，底部操作按钮保持可用。设置窗口大小与位置会保存。
- Agent 接入页使用真实项目标志，移除白色底框，适配浅色、深色主题和高 DPI；随安装包保留对应来源和第三方许可。
- 点击波形颜色按钮时，自动关闭自动配色和默认样式继承；直接修改线宽或线型时，自动为当前通道单独保存样式。

10 组 Qt 测试全部通过，共 264 项通过、4 项可选环境测试跳过。安装包通过透明闪电图标、自定义中文目录安装、自动识别原路径升级、设置与用户文件保留、无 Qt SDK 环境启动、HTTP/STDIO MCP、运行中覆盖保护及卸载验证。开发用 Demo 和个人配置不进入正式安装包。
