# Serial Workbench 0.15.36

无需先打开工作台，命令行和 Agent 现在可以自动启动后台 MCP，并与 GUI 共享连接和数据。

- **原生命令行**：新增 `SerialWorkbenchCLI.exe`，支持 `start`、`status`、`show`、`stop`、`tools`、`call`、`mcp`，以 JSON 输出结果；可直接调用原生搜索、脚本试解析和其他 MCP 工具。
- **后台自动接入**：STDIO 桥默认启动或复用同一配置的后台实例，发现实际 MCP 端口；Agent 退出后后台继续运行。`show` 打开同一个实例，保留连接、搜索和脚本状态。
- **权限保持明确**：新配置默认只读；建立连接、发送数据和应用脚本仍需开启 AI 控制。首次启动可显式使用 `start --allow-control`；不会自动提高已运行实例的权限，也不会自动连接设备。需要交互认证的 SSH 可打开 GUI 后重连。
- **Agent 与 skill 同步**：设置中可选择后台自动启动，命令行支持 `install-skill` 和 `configure-agent`。内置、安装器与 GUI 分发的 skill 均增加 CLI、配置路径和后台生命周期说明；MCP 可读取 `read_usage_guide(topic="cli")`。
- **SSH 跨屏复制**：按住鼠标向终端上下边缘拖动可连续滚动并选择多行历史，滚轮也可扩展选区；新输出不再打断拖拽。

推荐 Windows x64 安装包。发行包包含 CLI、MCP 桥和运行库，无需另装 Python 或 Qt。

升级前关闭 GUI 和 Agent 的 MCP 桥；如后台仍在运行，执行旧安装目录中的 `SerialWorkbenchCLI.exe stop`。升级保留个人配置。升级后在“设置 → AI / MCP”更新 skill、配置 Agent 并重载该 Agent 的 MCP。

```powershell
.\SerialWorkbenchCLI.exe start
.\SerialWorkbenchCLI.exe call get_status
.\SerialWorkbenchCLI.exe show
```

验证：原生 CTest 18/18；最终包的 CLI 自动启动/权限/共享读写/搜索/脚本/GUI 接续，隔离安装升级卸载，便携 ZIP 和单文件启动均通过。九类 Agent 配置验证使用隔离样本，未逐一实连第三方 Agent；设备链路使用回环与模拟 SSH，未声称真实硬件测试。

## English

- Add a native JSON CLI for runtime lifecycle and direct MCP tool calls, including native log search and frame-script validation.
- Auto-start or reuse the selected settings profile through the STDIO bridge, discover its actual port, and keep the shared runtime alive when an Agent exits. Open the same instance with `show` without losing connections or GUI state.
- Keep new profiles read-only by default. Connection control, writes and script application still require explicit AI permission. `start --allow-control` applies only to a new instance; devices are not connected automatically. Interactive SSH authentication requires the GUI.
- Add automatic startup to Agent settings, CLI skill installation/configuration, and bundled CLI documentation available through `read_usage_guide`.
- Fix SSH selection across scrollback boundaries with edge dragging and wheel scrolling.

Close the GUI and MCP bridges before upgrading. Stop a running background instance with the old installation's CLI. Settings are retained; update skills and reload Agent MCP connections afterward. The setup, portable ZIP and single-file EXE include native runtimes and require no Python or Qt SDK.
