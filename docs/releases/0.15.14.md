# 0.15.14（未发布）

## 新增

- 独立更新窗口，展示新版本特性、修复说明、发布日期和安装包大小。
- 更新窗口可调整大小、最小化或隐藏。后台下载时可继续使用工作台，校验完成后手动选择安装时机。

## 修复

- SSH 终端随窗口大小和字号同步远端行列数，修复长输入换行错位、覆盖提示符的问题。
- 修复 SSH 中 Home/End 的按键兼容性，避免伪终端启动控制序列被误判为连接成功。
- 修复终端在右边界收到换行和光标控制时多换一行的问题。
- 字体、字号、粗细和斜体等完整样式在修改后立即保存，波形和解析数据区同步应用字体。

此版本当前仅生成本地安装包，尚未发布至 GitHub Release 或国内镜像。网站及版本自动同步在 ICP 备案期间保持冻结。
