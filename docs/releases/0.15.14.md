# Serial Workbench 0.15.14

## 新增

- 实时数值并入波形页，可独立显示或隐藏、拖动调整面板宽度。JSON、XML 拆成独立页面，旧配置自动迁移；JSON 助手提供自动格式化、中文语法错误定位，以及可复制的 cJSON 解析和组装示例代码。

- 波形通道支持右键设置颜色、线宽和线型，可恢复或继承页面默认样式。X/Y 轴支持自定义名称与单位，常用特殊单位可点击选择，X 轴可按采样间隔换算显示刻度；设置随页面自动保存。

- 独立更新窗口，展示新版本特性、修复说明、发布日期和安装包大小。
- 更新窗口可调整大小、最小化或隐藏。后台下载时可继续使用工作台，校验完成后手动选择安装时机。
- AI / MCP 设置增加串口、TCP、UDP、SSH 四个独立开放开关，立即生效并自动保存。关闭后，AI 无法查看或操作该协议的连接、收发历史和解析结果，本地收发不受影响；TCP 客户端和服务端统一管理。
- SSH 支持密码、私钥口令及首次连接的主机指纹确认，可选择使用 Windows 加密记住密码。增加当前主机的缓存清除入口，分别管理保存的密码和指纹，设备变更后可重新认证。

## 修复

- JSON 助手生成代码按字段命名，自动处理关键字与重名；常用函数说明精简为 cJSON 解析、组装和内存释放，项目链接适配浅色与深色主题。

- 波形、实时数值和 JSON/XML 的冻结复选框统一为暂停/继续图标，支持键盘操作和中文悬停提示；修复已拔除串口仍以历史配置出现在数据来源列表的问题。

- 波形设置窗口放大后保持紧凑布局，并保留上次窗口大小和设置页。直接编辑通道样式时自动切换为独立设置，再次打开显示已保存值；演示通道名称和线宽单位使用中文。

- SSH 终端随窗口大小和字号同步远端行列数，修复长输入换行错位、覆盖提示符的问题。
- 修复 SSH 中 Home/End 的按键兼容性，避免伪终端启动控制序列被误判为连接成功。
- 修复终端在右边界收到换行和光标控制时多换一行的问题。
- 字体、字号、粗细和斜体等完整样式在修改后立即保存，波形和解析数据区同步应用字体。
- 恢复数据字体选择按钮的边框；字体对话框的标签、效果选项和确认按钮使用中文，字体名称保留原名。中文翻译内置于程序，安装后无需额外下载。

- 调整菜单图标的左侧留白，使新建页面菜单中的图标与文字间距更均匀。
