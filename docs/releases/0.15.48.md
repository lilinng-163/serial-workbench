# Serial Workbench 0.15.48

- Agent 默认可发现 35 个 MCP 工具。通过 `read_events` 和准确的连接 ID 读取单个设备，空闲的 OpenOCD 板卡页可在工作台关闭。已有脚本仍能直接调用 `read_all_events` 和 `close_openocd_view`。
- 桌面工作台可见时，MCP 导入 3D 模型、新建 OpenOCD 页面或首次挂载 OpenOCD 页面会切到相应标签。OpenOCD 新建页可传 `activate=false` 保留当前标签。
- 后台 MCP 可继续收发数据，打开同一设置对应的工作台即可接续。

## English

- Agents discover 35 MCP tools by default. Use `read_events` with an exact connection ID to read device output and close idle OpenOCD pages from the workbench. Existing scripts can still call `read_all_events` and `close_openocd_view` by name.
- When the desktop workbench is visible, MCP model imports and newly created or first attached OpenOCD pages switch to the corresponding tab. Pass `activate=false` when creating an OpenOCD page to keep the current tab.
- Background MCP can continue sending and receiving data. Open the workbench using the same settings to resume in the GUI.
