# Serial Workbench 0.15.42

- OpenOCD 每个板卡页现在有独立的「固件烧录」和「RTT 日志」工作区。RTT 终端占用主区域，连接参数收进独立窗口。支持 ANSI 彩色日志、弹出终端、暂停、复制和导出。
- RTT 可由工作台启动 OpenOCD，也可连接已有 RTT 服务。TCP 意外断开后会在有限时间内重连同一服务，保留任务、日志和读取进度。连接日志区分初始化、TCP 连接和等待固件输出。
- `Ctrl+F` 支持大小写、全词、正则及 `&&` / `||`。`search_openocd_rtt` 和界面共用筛选条件，`read_openocd_rtt` 提供原始日志和独立游标。
- 固件表格预留三行，最多同时显示六个分段。长路径保留文件名，悬停可查看完整路径。

Windows x64 提供安装包、便携 ZIP、单文件 EXE 和 SHA-256 校验文件。通过 CMSIS-DAP 在 STM32F103 上验证了彩色 RTT 日志与 MCP 搜索，断线续收使用模拟服务验证。

## English

- Each OpenOCD board tab has separate flashing and RTT workspaces. The RTT console fills the main area, with connection settings in a separate window. It supports ANSI colors, a pop-out console, pause, copy and export.
- Start OpenOCD from the workbench or connect to an existing RTT service. After an unexpected TCP disconnect, the workbench retries the same service for a limited time and preserves the job, logs and read cursors. Connection diagnostics distinguish initialization, TCP connection and waiting for firmware output.
- Use `Ctrl+F` to search with case, whole-word, regex and `&&` / `||` options. `search_openocd_rtt` shares the GUI filter, and `read_openocd_rtt` provides raw logs with independent cursors.
- The firmware table reserves three rows and shows up to six segments at once. Long paths keep the filename visible, and hovering shows the full path.

Windows x64 installer, portable ZIP, single-file EXE and SHA-256 checksums are available. Color logs and MCP search were verified on STM32F103 with CMSIS-DAP. Reconnection was tested using a simulated service.
