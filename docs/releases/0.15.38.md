# Serial Workbench 0.15.38

修复收发终端大面积选中文字时出现的一像素横缝。

- 终端相邻字符的背景共用对齐后的物理像素边界，避免特定字号或显示缩放下出现空隙；选区和 ANSI 彩色背景均已修复。
- 保持文字位置、复制范围、历史滚动和键盘操作。已有连接、主题、3D 模型及 MCP 配置沿用原设置。
- 在 100%、125%、150%、200% 缩放及 11、12、13pt 字号下完成 24 组像素回归；终端测试 61 项通过，Windows 实际窗口已检查大面积拖选。

推荐安装包 `SerialWorkbench-0.15.38-windows-x64-setup.exe`。另提供便携 ZIP、单文件 EXE 和 `SHA256SUMS.txt`，无需另装 Qt 或 Python。安装器处理同目录工作台与 MCP 桥的占用；升级后重新连接 Agent 的 MCP。

发行构建的完整原生 CTest 22/22 通过。本次复用既有打包流程，没有重复进行安装升级和硬件测试。

## English

- Fix one-pixel gaps between terminal cell backgrounds at certain font sizes and display scales. Both text selections and ANSI backgrounds now share physical pixel boundaries.
- Preserve text placement, selection/copy ranges, scrollback and keyboard behavior, along with existing connection, theme, 3D and MCP settings.
- Verify 24 pixel regression cases across 100%, 125%, 150% and 200% scales and 11, 12 and 13pt fonts. All 61 terminal tests pass, with large selections also checked in a real Windows window.

The Windows x64 setup installer is recommended. Portable ZIP, single-file EXE and checksums are also available; Qt and Python do not need to be installed. Reconnect Agent MCP sessions after upgrading.

All 22 native CTest suites passed for the release build. This update reuses the existing packaging process; installer-upgrade and hardware tests were not repeated.
