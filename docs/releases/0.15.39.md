# Serial Workbench 0.15.39

设置的「Agent 接入」页恢复品牌配色。Antigravity 使用官方渐变，TRAE 和 VS Code Insiders 使用绿色标识，Kilo Code 使用黄黑标识，Qwen Code 和 Zed 使用品牌蓝，Kimi Code 恢复蓝色圆点，Cursor 使用官方灰阶立体标识。官方单色图标随主题选用黑色或白色。

推荐 Windows x64 安装包，另有便携 ZIP、单文件 EXE 和 SHA-256 校验文件。已检查 Windows 浅色和深色主题下的图标显示。

## English

The Agent settings page now displays the original brand colors for Antigravity, TRAE, VS Code Insiders, Kilo Code, Qwen Code, Zed, Kimi Code, and Cursor. Official monochrome marks adapt to the active theme. The icons were checked in light and dark themes on Windows.

Choose the Windows x64 installer, portable ZIP, or single-file EXE. SHA-256 checksums are included.
