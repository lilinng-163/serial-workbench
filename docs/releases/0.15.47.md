# Serial Workbench 0.15.47

- Antigravity 桌面版、IDE 和 CLI 共用 `~/.gemini/config/`。即使只有桌面应用数据目录，安装器也可识别 Antigravity，并将完整 Skill 安装到共享目录。
- MCP 配置为空或只有空白时可直接初始化，保留其他 MCP 服务。默认 STDIO；HTTP 写 `url`，检查兼容已有的 `serverUrl`，拒绝旧式 `/sse` 地址。
- Skill 检查兼容 LF 与 CRLF，避免只因换行格式不同而提示修复。

## English

- Use Antigravity’s shared global MCP and skill directories across the desktop app, IDE and CLI. The installer also detects the desktop app data directory without requiring `agy` on PATH.
- Initialize empty or whitespace-only MCP files while preserving other servers. STDIO remains the default. HTTP configuration writes `url`, reads legacy `serverUrl` entries, and rejects legacy `/sse` endpoints.
- Treat LF and CRLF as equivalent when checking Antigravity’s installed skill guides.
