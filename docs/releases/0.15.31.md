# Serial Workbench 0.15.31

AI 协作与界面同步更新。

- AI 可直接调用收发页、JSON/XML 与已打开小窗的搜索，大小写、全词、正则及逻辑开关与界面同步，无需生成 grep 命令。
- 新增串口脚本读取、离线分块试解析和应用接口。应用需要 AI 控制权限及最新 revision，保护未保存的界面编辑和正在进行的试解析。
- AI 打开连接后显示对应收发页，应用脚本后展示代码和启用状态。活动提示可打开调用详情和全部记录，调用日志支持跟随最新记录及回看。
- 安装时可选 Codex、Claude Code、OpenCode、Pi skill，默认不选；已有不同内容先备份。启动与端口变化时只读检查 Agent 地址，配置更新仍由用户操作。

推荐下载 `SerialWorkbench-0.15.31-windows-x64-setup.exe`。另提供单文件 EXE、便携 ZIP 和 SHA-256 校验文件，无需安装 Qt 或 Python。升级前关闭工作台与 MCP 桥，安装器沿用原安装目录并保留设置。升级后重载 Agent 的 MCP 连接，以获取新增的工具。

## English

- Search the actual GUI display through MCP, sharing case-sensitive, whole-word, regex and logical matching options.
- Inspect, validate and apply serial frame parsers. Offline chunk tests leave live sessions unchanged; applying requires AI control permission and a current revision, and protects unsaved GUI edits.
- Display AI-opened connections and applied scripts in the GUI. Activity notices link to call details and audit history; the audit follows new entries while preserving the position and selection when browsing older calls.
- Optionally install Codex, Claude Code, OpenCode or Pi skills. Startup endpoint checks are read-only; configuration updates remain manual.

Use the Windows x64 setup installer for normal installation. A single-file launcher, portable ZIP and SHA-256 checksums are also available. Close the application and MCP bridge before upgrading; settings are retained. Reload the Agent MCP connection after upgrading to discover the new tools.
