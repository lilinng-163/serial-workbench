# Serial Workbench 0.15.40

- 原始文件发送可设置每块字节数和块间隔，方便适配处理速度较慢的设备。发送超时计入线路时间，修复低波特率下的提前超时。
- 新增 XMODEM-1K CRC 发送，设备支持时可用 1024 字节块减少确认次数，短尾块使用 128 字节。原有 128 字节 CRC 模式继续可选。
- 修复取消后立即重开时残留回调干扰新传输的问题。接收半包按数据间的空闲时间判断超时。

Windows x64 提供安装包、便携 ZIP、单文件 EXE 和 SHA-256 校验文件。34 项串口传输测试通过。虚拟串口 Demo 的原始发送和 XMODEM-1K 均通过完整文件校验，后者也通过 CRC 错误重传验证。

## English

- Configure raw file chunk size and delay to accommodate slower receivers. Include estimated wire time in the timeout budget for low baud rates.
- Send with XMODEM-1K CRC when the receiver supports 1024-byte blocks, with 128-byte blocks for short tails. The original 128-byte CRC mode is still available.
- Cancel queued sends when a transfer ends and time out partial receive frames based on line inactivity.

Windows x64 installer, portable ZIP, single-file EXE, and SHA-256 checksums are available. All 34 serial transfer cases passed. Virtual serial transfers preserved file integrity in both raw and XMODEM-1K modes, including recovery from a CRC error.
