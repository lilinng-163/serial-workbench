# Serial Workbench 0.15.43

- 左侧连接区新增离线「快速上手」教程，也可按 F1 打开。包含串口连接、收发、常见问题和波形、RTT、MCP 的入口指引。
- 教程可一键打开本地演示波形，无需连接设备。

## English

- Open the offline quick-start tutorial from the connection sidebar or by pressing F1. It covers first-time serial setup, sending and receiving, troubleshooting, and where to find waveforms, RTT, and MCP.
- Start a local waveform demo from the tutorial without connecting hardware.
- Fix clipped labels in the send line-ending selector. All four choices fit in the compact window layout.
