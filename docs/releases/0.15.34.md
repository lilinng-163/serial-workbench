# Serial Workbench 0.15.34

主色与撞色分工、预选背景统一和输入框细节更新。

- **双色主题**：设置 → 外观 → 主题色现在分为“主色（背景/面板）”和“撞色（按钮/链接/选中）”。主色只改变背景、面板和文字的色相；撞色接管默认主题中橙色强调色所在的组件，包括主按钮、工具栏动作图标、链接、选中、焦点、勾选、滑块、进度、发送、TX、关于页链接、rail 激活图标和波形第一条线。
- **独立设置**：两行都支持选色盘、`#RRGGBB` / `#RGB` 输入、应用和恢复默认；设置分别保存，重启及分离窗口同步。未单独设置撞色时使用默认暖橙色，不再自动生成互补色。
- **预选统一**：菜单、列表、页签、下拉项和树形项的悬停/预选背景统一使用撞色浅色；选中页签底色、页签文字、勾选按钮文字和描边按钮悬停/焦点恢复默认角色，不再把撞色铺到错误位置。
- **细节**：上移颜色输入框右侧的清除按钮，改善窄设置窗口中的对齐。
- **保持不变**：GUI 与 AI 继续共享连接并各自读取历史；MCP 的 17 个工具、协议权限、脚本读写/离线试解析和原生搜索保持 0.15.31 / 0.15.32 / 0.15.33 的行为。

推荐下载 `SerialWorkbench-0.15.34-windows-x64-setup.exe`。另提供单文件 EXE、便携 ZIP 和 `SHA256SUMS.txt`，运行无需安装 Qt 或 Python。升级前关闭工作台与 MCP 桥；安装器沿用原目录并保留配置。使用 Agent 的用户升级后重载 MCP 连接，并在设置中检查 skill 与地址。

## English

- **Two-color theme**: Settings → Appearance → Theme color now separates the main color (backgrounds and text) from a contrast color for buttons, links, selection and focus. The main color only tints surfaces; the contrast color takes over every role previously using the default orange accent, including primary buttons, toolbar actions, links, focus, checkboxes, sliders, progress, send, TX, About links, the active rail icon and the first waveform series.
- **Independent controls**: both colors support the picker, `#RRGGBB` / `#RGB` input, Apply and Reset, persist independently and synchronize across light/dark themes, detached windows and monitors. If no contrast color is set, the warm default accent is used; no automatic complementary hue is generated.
- **Consistent preselection**: menu, list, tab, combo and tree hover/preselection backgrounds use the contrast tint; selected-tab backgrounds, tab text, checked-button text and outline-button hover/focus keep their default roles.
- **Detail**: the clear button in color inputs is raised for better vertical alignment in narrow Settings layouts.
- **Preserved behavior**: GUI/AI shared connections with independent reads, all 17 MCP tools, protocol permissions, parser read/write/offline validation and native GUI search remain unchanged.

The Windows x64 setup installer is recommended. Single-file and portable builds plus SHA-256 checksums are also available; no Qt or Python SDK is required. Close the application and MCP bridge before upgrading. Existing installation paths and settings are retained. Reload the Agent MCP connection and check its skill and endpoint in Settings after upgrading.
