# Serial Workbench 0.15.35

主题配色与浅深模式一致性更新。

- **清晰的主题色**：保留所选按钮填充原色，链接、图标、TX 日志、波形、焦点边框和选区自动调整明暗，修复白色撞色在浅主题、黑色撞色在深主题中难以辨认的问题。
- **统一窗口配色**：工作台、设置、分离窗口、收发小窗、工具提示和禁用文字共用主题调色板；深色数字箭头、黑白勾选标记与主题同步。
- **独立选择撞色**：无需先修改主色，即可设置按钮、链接与选中效果的撞色；选色盘和 `#RRGGBB` / `#RGB` 输入继续支持保存恢复。
- **一致的协议选择框**：“串口 / TCP / UDP / SSH”下拉框与其他输入框使用相同底色和边框，取消单独的高亮底色。
- **JSON 助手链接**：说明链接跟随当前主题，不再固定使用绿色、橙色或系统蓝色。

推荐下载 `SerialWorkbench-0.15.35-windows-x64-setup.exe`。另提供单文件 EXE、便携 ZIP 和 `SHA256SUMS.txt`，运行无需安装 Qt 或 Python。升级前关闭工作台与 MCP 桥，安装器沿用原目录并保留配置。Agent 用户升级后重载 MCP，并在设置中检查 skill 与接入地址。

## English

- Preserve the chosen button fill while adjusting accent text, icons, TX logs, waveforms, focus borders and selections for readable light/dark themes, including black and white accents.
- Share theme palettes across the workspace, Settings, detached windows, receive monitors, tooltips and disabled text. Adapt dark spin arrows and black/white checkmarks.
- Choose a contrast color independently of the main color, through the picker or `#RRGGBB` / `#RGB` input, with persistent settings.
- Match the protocol selector background and border to the other inputs.
- Follow the active theme for JSON assistant reference links.

The Windows x64 setup installer is recommended. Single-file and portable builds plus checksums are also available. Close the application and MCP bridge before upgrading; existing paths and settings are retained. Reload Agent MCP connections after upgrading.
