# 国内更新镜像

客户端读取 `https://162.14.72.194/updates/latest.json`，网站读取同一清单并使用同源 HTTPS 下载。清单包含版本、安装包 URL、大小、SHA-256、发布日期和更新说明。客户端下载完成并校验后才允许安装。

## 维护边界

网站由维护者使用本机私有工具发布，专用部署与同步脚本不随公共仓库分发。远端控制通过 Serial Workbench MCP 完成；安装包先完成上传与校验，再原子更新版本清单。公开发布后，从 HTTPS 完整下载安装包并核对大小与摘要。

服务器定时任务仅核验已有清单、安装包和校验文件，不访问 GitHub，也不会自行更新版本。客户端可用更新与网站下载内容以维护者已发布的镜像为准。

网站在进入页面、回到前台，以及前台每 60 秒刷新清单。安装包镜像与网站页面目录独立；保留旧版本用于回退。实际软件截图按捕获版本标注。

既有原生客户端要求清单安装包主机匹配 IP 镜像，网站将验证后的路径映射为自己的 HTTPS 域名。证书续期与版本发布相互独立。
