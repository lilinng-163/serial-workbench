# 像素掌机主题

串口调试工作台采用像素掌机的视觉语言：灰绿外壳、浅色显示面板、深绿导航轨道和琥珀操作按键。
数据区域保持大面积留白，像素风集中在字形、图标、边框和操作状态。

## 主题规则

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 外壳 | `#dce2d3` | `#1e2b25` |
| 显示面板 | `#f6f4e8` | `#24332b` |
| 参数背景 | `#e9ecdd` | `#2c3c32` |
| 正文 | `#28392f` | `#e1e5ce` |
| 操作强调 | `#dc8c38` | `#edaa50` |
| 导航轨道 | `#293e35` | `#17231d` |

字体统一采用内置 Fusion Pixel 8px 简体中文等宽字体，以 16px 显示正文、24px 显示品牌标题。
数据区使用同系列 12px 字体，默认以 18pt（96 DPI 下 24px）显示，可单独选字体和字号。已有自选字体保留；旧版默认字体迁移为像素字体。
边框、下拉箭头、复选框、滚动条和选中标记统一为直角。图标使用 16×16 网格；
按钮悬停用颜色反馈，按下时轻微位移，选中时显示实色按键和底边。

## 布局

```text
导航轨道 | 品牌与连接参数 | 连接标签 +
         |              | 收发 / 波形 / 数值 / 解析
         |              | 显示开关                  搜索 / 操作
         |              | 收发内容
         |              | -----------------------------
         |              | 发送缓冲
设置     | 连接提示       | 编码 / 换行 / HEX          发送
```

参数表单左对齐，连接与控件标签分层显示；主要操作只使用琥珀强调色。
连接状态仍有独立的绿色、红色和文字提示。波形曲线保留平滑绘制以便准确读数。
设置、菜单、控件及独立窗口使用相同主题。

字体来源与许可证见 [字体说明](../native/fonts/README.md)。
