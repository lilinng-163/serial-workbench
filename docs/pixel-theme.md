# 像素掌机主题

串口调试工作台采用像素掌机的视觉语言：灰绿外壳、浅色显示面板、深绿导航轨道和琥珀操作按键。
数据区域保持大面积留白，像素风集中在品牌标题、图标、边框和操作状态。

## 主题规则

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 外壳 | `#dce2d3` | `#1e2b25` |
| 显示面板 | `#f6f4e8` | `#24332b` |
| 参数背景 | `#e9ecdd` | `#2c3c32` |
| 正文 | `#28392f` | `#e1e5ce` |
| 操作强调 | `#dc8c38` | `#edaa50` |
| 导航轨道 | `#293e35` | `#17231d` |

菜单、连接参数和说明使用平滑的微软雅黑 UI（常规文字 14px，辅助说明 13px）。
品牌短标题保留内置 Fusion Pixel 8px 字体，以 24px 显示。
收发日志和终端默认使用 Cascadia Mono / Consolas，12pt；中文由系统字体回退显示。
正文启用抗锯齿；像素风由配色和控件轮廓保持，避免小字号点阵汉字难以辨认。
0.9.0 的默认 18pt 点阵数据字体自动迁移为推荐等宽字体，其他自选字体保留。
设置中的「恢复推荐字体」仅恢复数据字体，Ctrl + 滚轮可调整字号。
边框、下拉箭头、复选框、滚动条和选中标记统一为直角。图标使用 16×16 网格；
下拉箭头使用 14×8 的实心阶梯图形，保持文字同等对比度。
图标悬停和键盘焦点用图标变色反馈；鼠标点击后移开恢复普通颜色，开关启用时保留选中颜色。按下时仅图标或文字轻微位移；图标不绘制悬停框。标签当前页仍用琥珀底边标识。

收发工具栏直接提供暂停 / 继续、清空、跟随最新数据与日志导出；发送栏直接提供循环发送和毫秒间隔，不使用省略号隐藏这些操作。设置、垃圾桶、播放和暂停图标保持像素轮廓，并通过清晰的形状区分功能。

接收区默认自动换行，工具栏的折行箭头可以切换；关闭后，长消息显示横向滚动条。切换只影响排版，原始报文、选择和日志导出保持完整。换行选择随页面显示设置保存，交互终端使用自己的字符网格。下拉列表采用平面列表样式，去掉外层黑框和上下菜单滚动带。

## 布局

```text
导航轨道 | 品牌与连接参数 | 收发 / 控件标签 +
         |              | 显示开关                  搜索 / 操作
         |              | 收发内容
         |              | -----------------------------
         |              | 发送缓冲
设置     | 连接提示       | 编码 / 换行 / HEX          发送
```

参数表单左对齐，收发与控件使用同一条主标签栏；「＋」先选择页面类型。收发页不再显示内部标签栏，控件页通过数据来源选择已有连接并自动收起连接参数。主要操作只使用琥珀强调色。
连接状态仍有独立的绿色、红色和文字提示。波形曲线保留平滑绘制以便准确读数。
设置、菜单、控件及独立窗口使用相同主题。

字体来源与许可证见 [字体说明](../resources/fonts/README.md)。

## 0.11.0 页面布局

- 「＋」提供收发页面和控件页面入口，控件类型在二级菜单选择。
- 主标签栏统一承载收发、波形、实时数值及解析页面，收发区域少占一层标签栏。
- 控件页直接选择已有数据来源，自动收起连接参数；分离后的控件继续读取原连接。
- 页面类型、来源和控件参数独立保存，旧配置中的多个控件保留并迁移。
- Release 构建通过；21 项 Qt 测试在离屏及正常 Windows 桌面均通过。
- 打包版 MCP HTTP / STDIO、权限、独立读取、软件回环及网络回归通过。
- Windows 实图检查覆盖新建菜单、浅色 / 深色、窄窗口及独立控件窗口。
