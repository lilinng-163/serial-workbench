# 像素掌机主题

串口调试工作台采用像素掌机的视觉语言：灰绿外壳、浅色显示面板、深绿导航轨道和琥珀操作按键。
数据区域保持大面积留白，像素风集中在品牌标题、图标、边框和操作状态。

## 主题规则

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 外壳 | `#dce2d3` | `#1e2b25` |
| 显示面板 | `#f6f4e8` | `#24332b` |
| 参数背景 | `#e9ecdd` | `#2c3c32` |
| 正文 | `#28392f` | `#e1e5ce` |
| 操作强调 | `#dc8c38` | `#edaa50` |
| 导航轨道 | `#293e35` | `#17231d` |

菜单、连接参数和说明使用平滑的微软雅黑 UI（常规文字 14px，辅助说明 13px）。
品牌短标题保留内置 Fusion Pixel 8px 字体，以 24px 显示。
收发日志和终端默认使用 Cascadia Mono / Consolas，12pt；中文由系统字体回退显示。
正文启用抗锯齿；像素风由配色和控件轮廓保持，避免小字号点阵汉字难以辨认。
0.9.0 的默认 18pt 点阵数据字体自动迁移为推荐等宽字体，其他自选字体保留。
设置中的「恢复推荐字体」仅恢复数据字体，Ctrl + 滚轮可调整字号。
边框、下拉箭头、复选框、滚动条和选中标记统一为直角。图标使用 16×16 网格；
按钮悬停用颜色反馈，按下时轻微位移，选中时显示实色按键和底边。

## 布局

```text
导航轨道 | 品牌与连接参数 | 连接标签 +
         |              | 收发 / 波形 / 数值 / 解析
         |              | 显示开关                  搜索 / 操作
         |              | 收发内容
         |              | -----------------------------
         |              | 发送缓冲
设置     | 连接提示       | 编码 / 换行 / HEX          发送
```

参数表单左对齐，连接与控件标签分层显示；主要操作只使用琥珀强调色。
连接状态仍有独立的绿色、红色和文字提示。波形曲线保留平滑绘制以便准确读数。
设置、菜单、控件及独立窗口使用相同主题。

字体来源与许可证见 [字体说明](../resources/fonts/README.md)。
