# 实时端口发现（0.10.1）

端口标签显示「实时扫描」，不再提供手动刷新按钮。Windows 设备变化会触发扫描，并每 500 ms 补查一次。扫描仅枚举设备，不打开端口。

列表仅增删发生变化的行；下拉菜单展开时仍更新，不清空重建整个列表。端口说明与 USB Serial/JTAG 提示同步更新。

选中的 COM 端口消失后，输入字段立即回到 NULL，当前连接草稿也更新。启动、切换标签或移至独立窗口时，已失效的端口不会重新出现在字段中。插入新设备会加入列表，不会自动连接或擅自选择它。

手动输入期间保留文字、光标及选区；完成输入或建立连接前检查端口是否可用。输入不会被添加为扫描结果。开发用的 loop:// 仍可手动使用。

设备移除会主动通知已打开的串口连接，即使没有接收数据、驱动尚未报读写错误，也会进入「等待设备恢复」。保留原设备身份和恢复逻辑，字段清除后仍可停止该连接；扫描不会修改串口参数或消耗接收数据。

验证覆盖：

- 设备新增、移除及描述变更；未变化时不重置模型。
- 展开的下拉列表持续更新，已消失的选择变为 NULL。
- 输入保护、无效输入不插入列表、旧草稿端口清除。
- 独立窗口保留有效端口；无读写错误时主动进入设备恢复状态，原连接仍可手动停止。
- 图标悬停及键盘焦点只改变图标颜色，鼠标反馈仅轻微位移和缩放；移除边框与背景高亮，避免标签关闭按钮外溢。
- Release 编译，离屏与 Windows 桌面各 16 项测试通过；插拔状态由可控设备快照模拟，不打开真实硬件。
- 打包版 HTTP / STDIO 验证通过；真实 Windows 启动时，已不存在的 COM8 设置清除为 NULL。
