# JSON 助手与波形数值面板

「＋ → 新建控件页面」提供数值波形、JSON、XML 三种页面。JSON 与 XML 只显示各自的报文，可以同时选择同一个设备连接。原始收发记录和 MCP 的结构化结果仍由同一连接共享保存。

## 波形内的实时数值

在波形页点击「实时数值」显示右侧面板，再点一次或点击面板关闭图标即可隐藏。拖动中间分隔条调整宽度。面板读取每个来源最近一帧合法 `@wave` 报文中的字段，不混入脚本或 JSON/XML 结果。暂停图标同时暂停曲线和数值的显示，后台继续采集；继续后显示最新数据。

默认列出变量与当前值，悬停数值可查看完整值、来源和采样序号。面板开关和宽度随波形页面保存。旧版实时数值页会并入同一数据来源的波形页；没有对应波形页时创建一个波形页并打开数值面板。

## JSON 校验和格式化

在 JSON 页点击「JSON 助手」。如果已选择接收记录，会以该记录作为初始内容；也可以直接粘贴单行或多行 JSON，不要求连接设备。

输入后右侧自动展开并高亮显示。语法错误会显示中文说明、行号和列号，并在输入位置标记。支持对象、数组、字符串、数字、布尔值与 null；字段名和字符串使用双引号，末尾不加逗号，不接受注释。「展开输入」「压缩输入」分别把有效内容替换为多行或单行格式。错误输入不会覆盖剪贴板或保留上一次生成的代码。

输入上限为 1 MB，格式化支持最多 128 层嵌套。JSON 页从设备字节流中提取报文时，顶层仍需为对象或数组；助手中的粘贴校验也支持单个值。

## cJSON 解析和组装

有效 JSON 会自动生成两类代码：

- 「cJSON 解析」生成 `int parse_message(const char *text)`。它校验完整 JSON、字段和类型，读取示例结构中的值；返回 0 表示成功，-1 表示语法或结构不符。在代码中标注的位置加入自己的业务处理。
- 「cJSON 组装」生成 `char *build_message(void)`。它用输入示例中的值创建对象、数组和字段，返回紧凑 JSON 字符串。可以把示例常量替换为自己的变量；调用方使用 `cJSON_free()` 释放返回字符串。

生成的节点与数值变量按字段命名，例如 `humi` 和 `humi_value`；嵌套字段会带父级名，例如 `sensor_humi`。空格、连字符、中文等不能直接用于通用 C 标识符的内容会转换为安全名称，关键字与重名会自动避让，JSON 中的原始字段名保持不变。

「复制当前结果」复制当前标签的格式化内容或代码。「常用函数」提供解析、类型判断、字段和数组访问、创建节点、输出与内存释放的速查。代码需要在目标项目中引入 cJSON 库；本程序不会执行生成的 C 代码。

生成器支持最多 512 个值、32 层嵌套，不生成含空字符字符串的 cJSON 代码。数组按示例索引展开，实际长度可变化时应改成循环或按协议校验。解析代码中取得的字符串属于解析树，应在 `cJSON_Delete(root)` 前使用或复制。cJSON 数字为 double，完整保留超大整数时建议使用字符串。

生成的函数和所有权处理依据 [cJSON 官方 API](https://github.com/DaveGamble/cJSON)。开发验证用官方 1.7.19 源码将对象、数组、中文、转义字符及单值示例分别按 C99 和 C++17 编译运行，并测试分配失败时的释放路径；测试依赖只放在开发构建目录。

旧版混合 JSON/XML 页会迁移为两个页面；此前选择「仅 JSON」或「仅 XML」的页面保留对应类型。两个新页面仍共享后台解析，不会相互关闭解析器。
