# 窗口尺寸与滚动布局

设置窗口支持缩小到 440×320，关闭后记住尺寸与位置。AI / MCP 整页支持滚动，页面内的连接表、日志表和 Agent 列表继续按可用空间调整。

自定义二级窗口将可滚动内容与底部操作区分开。空间不足时可以使用滚轮或滚动条访问后续字段，保存、取消、传输和下载等操作保留在窗口底部。坐标单位页内部单独滚动，较窄时表单标签自动换行。

| 窗口 | 检查的小尺寸（逻辑像素） |
| --- | --- |
| 设置：外观、AI / MCP、关于 | 440×320 |
| 曲线样式 | 400×240 |
| 坐标轴与单位 | 480×280 |
| 文件传输 | 480×280 |
| 更新详情 | 440×280 |
| JSON 助手、脚本编辑 | 560×320 |
| SSH 密码、指纹确认、缓存清除 | 440×260 |
| 波形报文说明 | 360×240 |

字体与颜色选择器使用 Qt 自带布局的内容最小尺寸，检查放大后可以再次缩回。
