# 3D 模型与串口姿态

在 **+ → 新建控件页面 → 3D 模型** 中导入模型，选择已连接的串口或网络连接。模型页、收发页、波形页和 MCP 共用连接与数据；模型页只读取数值，不发送报文、不自动连接设备，也不会清除其他页面的历史。

## 导入与操作

- 支持 STL（ASCII、二进制及多个 solid）、Wavefront OBJ、PLY（ASCII、大小端二进制）的网格几何。
- 点击“导入模型”或拖入一个文件。导入在后台完成；读取失败时保留当前模型。每个文件最大 64 MiB、最多 50 万三角面；多边形面会三角化。
- 当前显示网格形状，颜色跟随软件主题；不读取 MTL、纹理、骨骼动画或材质，不支持 STEP/IGES、FBX、GLTF。CAD 模型可先导出 STL/OBJ。
- 左键拖动旋转视角，中键拖动平移，滚轮缩放；双击或“适配视图”找回模型。可切换立体、正视、右视、俯视图。
- 每页一个模型；需要多个模型时新建多个页面。标签可分离到独立窗口。

页面会保存文件绝对路径、字段绑定、轴映射、模型比例、初始对齐、暂停状态和视角。模型文件仍需保留在原路径；移到另一台电脑或文件被移动后重新导入即可。

## 从数据驱动模型

默认使用现有 `@wave` 数值通道，逐帧读取最新数据。例如 MCU 周期发送：

```text
@wave x=0.1,y=0.2,z=0.3,roll=10,pitch=20,yaw=30
```

每帧末尾发送 CR、LF 或 CRLF。完整规则见[波形协议](wave-protocol.md)。在“位置”页分别绑定 `x`、`y`、`z`；“姿态”页默认绑定 `roll`、`pitch`、`yaw`，单位为角度，顺序为 ZYX 内禀旋转。

每个字段都可设置 `输出值 = 输入值 × 倍率 + 偏移`。例如毫米转米填倍率 `0.001`。位置/欧拉角通道留空时原始值为 0，可用偏移设置常量；四元数留空时 W 原始值为 1，X/Y/Z 为 0。倍率与偏移仍会应用到这些常量。

二进制串口协议可切换到“脚本解析结果”，绑定解析脚本 `emit` 输出的数值字段。嵌套对象使用 `imu.roll` 这样的路径；普通 JSON 日志不会自动变成模型数据。请先按[脚本指南](frame-scripts.md)试解析并启用脚本，再在模型页选字段。

绑定的所有分量必须出现在同一帧。缺字段、非数值、无效四元数或重复目标轴时，会提示并保留上一有效姿态，不跨帧拼接分量。网络多对端时可选择一个对端，分量不跨对端混用。暂停只停止模型更新，后台继续接收；恢复时显示最新帧。断线重连后等待新的完整帧。

## 欧拉角和四元数

欧拉角支持六种不重复轴顺序：`XYZ`、`XZY`、`YXZ`、`YZX`、`ZXY`、`ZYX`；可选内禀（随动轴）或外禀（固定轴），以及角度或弧度。X/Y/Z 字段始终表示绕对应输入轴的角度，顺序决定组合方式。

默认姿态矩阵为 `Rz(yaw) · Ry(pitch) · Rx(roll)`，作用于列向量，正角遵循右手定则。内禀 XYZ 等价于外禀 ZYX 使用同一组 X/Y/Z 角度。这里不提供重复轴的 XYX 等表示法。

四元数模式分别绑定 W/X/Y/Z，不依赖报文中的字段顺序；使用 Hamilton 四元数表达从模型局部到世界的主动旋转，自动归一化。例如绕 +Z 旋转 90°：

```text
@wave qw=0.70710678,qx=0,qy=0,qz=0.70710678
```

若设备输出的是反向旋转（世界到局部），可给 X/Y/Z 三个四元数分量设置倍率 `-1`，W 保持不变。零或极小四元数（最大分量小于 `1e-12`）会拒绝更新。

## 自定义坐标轴与模型原点

视图世界坐标固定为右手系、Z 向上。进入“坐标轴”，分别选择输入 X/Y/Z 对应世界的 `+X / −X / +Y / −Y / +Z / −Z`，三个目标轴不能重复，支持轴交换与反向。例如设备 Y 向上时，可设置输入 X→+X、Y→+Z、Z→−Y。

设这个轴变换为 C，位置按 `p世界 = C · p输入` 换算，姿态按 `R世界 = C · R输入 · C⁻¹` 换算；同样适用于左右手坐标约定转换。模型文件导出方向不同，则用下面的“模型初始对齐”单独调整，不需要改串口报文。

模型最终矩阵顺序为：平移 × 遥测姿态 × 初始 Z/Y/X 对齐 × 模型比例 × 原点平移（作用到顶点时从右往左）。默认将网格包围盒中心作为旋转原点；取消“模型中心作为旋转原点”则保留文件原点。模型比例只缩放模型尺寸，位置倍率独立配置；不自动猜测 CAD 文件的长度单位。

## 验证范围

原生测试覆盖文件格式、损坏文件、欧拉角/四元数计算、轴映射、共享帧读取、暂停/复位、保存恢复；Windows 实窗口测试另外检查渲染、主题、鼠标旋转及标签分离/回收。无显卡的 `offscreen` 测试不会执行实际渲染；这也不等同于真实 IMU 或 MCU 硬件联调。
