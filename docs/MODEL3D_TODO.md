2. **标签与面板连续**：修复位置、姿态、坐标轴、模型标签和下方面板的空缺、背景断层。检查浅深主题及 Windows 100% / 125% / 150% 缩放。
3. **简化旋转顺序入口**：用户希望删除 XYZ / XZY / ZYX 选择，认为作用不明显。源码 `evaluateModelPose()` 确实使用顺序组合旋转；逐轴演示只有一个非零角，各种顺序本来相同。实施时简化常用界面，但兼容已有非默认顺序配置，不擅自改变其最终姿态。用多个非零角验证顺序差异，导出说明明确实际采用的约定。
4. **修复适配视图**：复现取景异常，覆盖模型旋转、平移、缩放、非居中模型、初始对齐及宽窄窗口。确保完整模型可见，适配后的相机参数可保存恢复。
5. **拖动后参数实时同步**：为相机旋转、平移、距离提供明确且实时同步的数值；覆盖鼠标拖动、滚轮、预设视角、适配及 MCP 修改。区别相机参数和模型姿态，不能让拖动相机意外改动串口通道绑定。GUI、保存配置与 MCP 回读一致。
6. **可调抗锯齿**：提供关闭和多个质量档位，改善模型与参考线边缘。查询并展示硬件实际生效能力，避免选项变化但渲染不变；保存恢复、MCP 配置及截图采用一致质量，检查性能开销。
