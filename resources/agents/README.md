# Agent logos

Marks identify the corresponding clients. Trademarks remain with their owners;
the application license does not grant rights to these brands. Assets are bundled
offline and never downloaded when opening settings.

| File | Source and preparation |
| --- | --- |
| codex.svg | OpenAI Blossom path from https://developers.openai.com/codex/; transparent monochrome mark, black/white according to theme. |
| claude.svg | Claude asterisk path from https://claude.com/; standalone mark in Claude terracotta. Shared by Claude Code and Claude Desktop. |
| opencode.svg, opencode-dark.svg | Official light/dark marks from https://opencode.ai/brand and https://github.com/anomalyco/opencode/tree/dev/packages/console/app/src/asset/brand (MIT). No favicon tile. |
| pi.svg | https://pi.dev/logo-auto.svg; viewBox fitted with clear space, original paths/colors preserved. |
| hermes.svg, hermes-dark.svg | https://github.com/NousResearch/hermes-agent/tree/main/assets (`icon-master.svg`, `icon-master-dark.svg`, MIT); only the outer app-tile rectangle removed, illustration and clipping retained; nested SVG viewport converted to an equivalent transform for Qt. |
| openclaw.svg | https://openclaw.ai/favicon.svg; official gradient lobster, original paths/colors preserved. |
| grok.svg | Grok logomark mirrored by https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/grok.svg (MIT). Original mark, black/white according to theme. Official brand: https://grok.com/. |

Monochrome marks use their black/white variants; brand colors and proportions are
preserved. The UI adds no background tile or border. Sources checked 2026-10-15.
Lobe Icons' MIT license is included in `lobe-icons-LICENSE`. Existing CC0 notices
are retained for previously distributed assets. No endorsement is implied.

The Devin and Kiro color assets and the Copilot, Windsurf, Cline, and Qoder neutral
vectors are from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons)
(`lobe-icons-LICENSE`). Neutral marks use light or dark ink for contrast.
Reference artwork includes the [Windsurf brand guidelines](https://windsurf.com/brand),
[GitHub Copilot extension](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot),
[Cline's extension icon](https://github.com/cline/cline/blob/main/apps/vscode/assets/icons/icon.png),
and [Qoder's site icon](https://qoder.com/favIcon.svg).

- VS Code: [Microsoft Codicons vscode.svg](https://github.com/microsoft/vscode-codicons/blob/main/src/icons/vscode.svg), CC BY 4.0 (`codicons-LICENSE`); colored blue for the card.
- Continue: [ContinueSignet.tsx](https://github.com/continuedev/continue/blob/main/gui/src/components/svg/ContinueSignet.tsx), Continue authors, Apache-2.0; extracted the original path, removed JSX attributes and cropped the empty viewBox margin.
