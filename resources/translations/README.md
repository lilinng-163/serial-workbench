# Qt 中文翻译

`qtbase_zh_CN.qm` 来自 Qt 6.11.1 官方发行包的 `translations` 目录，
对应源码为 `qttranslations/translations/qtbase_zh_CN.ts`。

该文件嵌入程序资源，用于字体对话框的中文界面，不依赖用户安装 Qt。
字体家族名称保留字体自身的名称。

来源：https://code.qt.io/cgit/qt/qttranslations.git/tree/translations/qtbase_zh_CN.ts?h=v6.11.1

Qt 翻译的许可证与声明随安装包保存在 `licenses/Qt/qttranslations`。
