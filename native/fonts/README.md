# Fusion Pixel Font

The application embeds the unmodified Simplified Chinese, 8px and 12px monospaced OTFs
from [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font), release
2026.09.01. No system font installation is required.

See `OFL.txt` and the upstream component notices under `LICENSES/`.

Official archive: `fusion-pixel-font-8px-monospaced-otf-v2026.09.01.zip`

Archive SHA256: `bfa39b3b9943aaa7f9266839e42dbbcd2b76abba37d60379a0ca10b225450ad9`

The 12px archive is `fusion-pixel-font-12px-monospaced-otf-v2026.09.01.zip`,
SHA256 `52f90d89a51ad49a1227b3d68e3d378edcd8571fe5172bf10d89c7b4ae4a7356`.

At 96 DPI, UI text uses the 8px face at 16px (2x), branding at 24px (3x), and
data uses the 12px face at 18pt / 24px (2x).
The default font uses unsmoothed glyphs. A user-selected data font retains normal
font rendering and can be restored to the pixel default in Settings.
